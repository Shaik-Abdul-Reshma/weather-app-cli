### Description
A simple Command Line Interface Weather App that fetches live weather data for any city.

### Features
- Input any city name and get real-time weather
- Displays Temperature (°C/°F), Condition, Humidity, Wind Speed, Feels Like
- Uses free wttr.in API - no API key required
- Built with Python standard library only (urllib, json)

### How to Run

python weather.py
